# Design

## Context

`users` хранит `first_name`, `middle_name`, `last_name` — `varchar(255)`, все допускают `NULL`. Строки создают signup и
`POST /api/users`; в обоих имя необязательно, поэтому есть User совсем без имени.

## Decisions

### Перенос данных, а не очистка таблицы

Выбор владельца после сравнения. Удалить старые строки было бы допустимо для pet-проекта, но только ручным сбросом
локальной БД: `DELETE` внутри миграции выполнится везде, где её запустят. Перенос стоит 1 оператор `UPDATE` и учит
главному в миграции с данными.

### Правило переноса

`display_name = coalesce(nullif(left(concat_ws(' ', first_name, middle_name, last_name), 100), ''), 'User')`.

- `concat_ws` пропускает `NULL`: `('Ada', NULL, 'Lovelace')` → `'Ada Lovelace'`.
- `left(…, 100)` укладывает три поля по 255 символов в новую колонку.
- Пустой результат заменяется на `'User'`. Выбор владельца: такие User неотличимы друг от друга, но уникальности Display
  Name и не требует. Отклонено: часть email до `@` — email приватный, а Display Name попадёт в Public Profile;
  `'User ' || left(id::text, 8)` — показывает кусок внутреннего id.

### Порядок шагов в одной миграции

1. `ADD COLUMN display_name varchar(100)` — пока без `NOT NULL`, иначе добавление упадёт на существующих строках.
2. `UPDATE` по правилу переноса.
3. `SET NOT NULL`.
4. `DROP COLUMN` трёх старых полей.

`PgMigrator` выполняет все ожидающие миграции в одной транзакции (`Migrator.ts`, `sql.withTransaction(run)`), а DDL в
PostgreSQL транзакционный. Если любой шаг упадёт, таблица останется в исходном виде.

### Контракт

`displayName` — `Schema.Trim` с длиной 1–100 в signup, `POST /api/users` и `PUT /api/users/:id`. `PUT` заменяет
запись целиком, поэтому поле обязательно и там. `varchar(100)` в БД совпадает с пределом схемы.

## Risks

- `DROP COLUMN` необратим: если правило переноса ошиблось, исходных трёх полей больше нет. Поэтому перенос проверяется
  тестом на строках старого вида до удаления колонок.
- `left(…, 100)` обрезает длинное имя без предупреждения; для текущих данных pet-проекта это допустимо.
