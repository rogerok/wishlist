## Заметки

- Effect 4.0.4: настройки разбора тела берутся из аннотации API, переданного в `HttpApiBuilder.group(AppApi, …)`;
  аннотация на тестовом `HttpApi` ничего не меняет. Schema без настроек лишний ключ молча отбрасывает.
- `Effect.context<A | B>()` возвращает весь контекст fiber, параметр сужает только тип.
- `layer()` из `@effect/vitest` собирает слой на общем TestClock; прыжок `setTime` задевает таймеры пула — для
  фиксированного времени брать `excludeTestServices: true` и отдельный `TestClock.layer()`.
- Решения владельца: миграции только вперёд; публичный `POST /api/users` до 2.5; тесты по просьбе пишет агент,
  новые приёмы — с разбором.
