## Заметки

- Тестовому `PgClient` нужен `String.snakeToCamel` для результатов: локальный Kysely-адаптер обходит `CamelCasePlugin`.
  Схему в snake_case не переводить.
- `@effect/vitest` уже создаёт scope на каждый `it.effect`; отдельный `Effect.scoped` не нужен.
- `SchemaError` хранит вход только при `reportInput: true`.
- В auth `AuthService` берётся внутри запроса: тесту нужен `HttpRouter.provideRequest`;
  `ModeConfig` задавать изолированным ConfigProvider.
- Тесты: ступень 1 лестницы (чтение). Testcontainers впервые писались с пошаговой помощью.
- Пилот нового формата: [карта системы](reference/system-map.html), [разбор signup](lessons/0001-debrief-signup.html),
  затем login как ката.
